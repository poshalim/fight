# Битва за Полину

Стек: Vue 3 (Vite) + Tailwind CSS + Pinia + Socket.io

## Быстрый старт

1. Установка зависимостей

```
npm i
```

2. Запуск (клиент + сокет-сервер одновременно)

```
npm run dev
```

- Клиент: http://localhost:5173
- Socket.io сервер: http://localhost:3001

## Игровая логика (MVP)
- Комната на 2 человека. Первый вошедший — Некоглай, второй — Мафаня.
- Управление: A/D — движение, Space — прыжок, K или клик — удар.
- Урон по столкновению при близкой дистанции. HP уменьшается на 10.
- При обнулении HP появляется баннер победы и кнопка Рестарт.

## Заметки по разработке
- Спрайты сейчас — цветные прямоугольники с именами. Их легко заменить на изображения/GIF в `Game.vue`.
- Сетевые события изолированы в `src/stores/room.ts`. UI — отдельные компоненты.
- Tailwind подключен через `src/style.css` и настроен в `tailwind.config.cjs`.
